Best-Practice Direction
Controllers should stay thin. Business rules go into domain services. Prisma writes use transactions. Read endpoints should use select, pagination, indexes, and aggregated read models. Workflow writes should be idempotent and append WorkflowTransition + AuditLog. Backend must cache/index on-chain state for speed, but must fetch live on-chain state before privileged actions.
I would start with Phase 0 as the next concrete task: generate the route matrix, schema audit, endpoint usage report, and proposed ERD before touching code.
