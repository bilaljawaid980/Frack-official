## Remaining Production Hardening

The sandbox is ready for manual testing. Before production, the following should be hardened:

1. Add SPL Token-2022 CPI custody to trade escrow instead of sandbox state-only locking.
2. Wire asset-registry dispute, succession, custody-lapse, stale-NAV, and total-loss states into token-hook transfer denial paths.
3. Add a dedicated on-chain `declare_total_loss` instruction for exact Phase 3 parity.
4. Replace Phase 4 mock/readiness endpoints with approved real partner APIs.
